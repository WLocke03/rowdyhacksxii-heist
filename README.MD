Greetings future reader. This project is for the RowdyHacksXII hackathon! It is a showcase of vulnerability exploitation on a windows server, bypassing DEP and ASLR.

This project is composed of three parts:
- A web server with a stack overflow vulnerability
    - Team Opportunity: Team member builds HTTP server + web page
- A python script written to exploit the vulnerability
- A reverse shell payload to leverage the vulnerability
    - Team Opportunity: Team member creates cool shell theming
